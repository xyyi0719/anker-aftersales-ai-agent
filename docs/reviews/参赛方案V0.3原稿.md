## 二、方案成果展示

### 赛题理解

**对赛道命题的理解**：这道题要做一个能独立办完售后全流程的 Agent。按安克的三阶段框架，问答（L1）与引导（L2）行业已成熟，安克自身已达成 L3 闭环办理（独立托管率 70–80%、意图识别准确率 90%+）。真正的战场在 **L3 深化**：真实售后中仅 30% 是简单咨询，70% 是故障诊断、多平台多区域质保确认、退换货决策的复杂场景；而在这 70% 中，最危险的是 AI「乱办」——虚构质保承诺、编造召回答案，每一件都直接转化为赔偿与合规风险。**我们选择的题眼，是五个难点中被官方定义为「致命伤」的幻觉问题。**

**目标用户**：

- **安克全球消费者**：口语化、情绪化描述问题，常附故障照片，期望一次求助把事办成；
- **安克售后运营团队**：要的是 AI 办的每一件事**可解释、可审计、不越权**。

### 具体方案说明（突出 AI 能力）

方案包含三个核心功能点：一个主打深度（功能点一），两个保障完整性（功能点二、三）。

#### 功能点一（主打）：办得安全——幻觉四道防线（对应难点「幻觉」「接稳」）

**做什么**：让 AI 客服的每一次办理都被约束在 SOP 之内——检索不到的信息诚实升级、绝不编造；质保、召回等高危问题禁止模型自由回答；客户情绪升级至投诉风险时立即转人工。

**怎么做**：四道防线层层递进，每层独立可测试：

1. **流程锁**：售后 SOP 以状态机（故障树 JSON）固化，流程走向由状态机决定，LLM 只负责理解用户回答与生成话术，没有流程决策权——模型无法「跳过核保直接承诺换新」；
2. **出处锁**：政策类回答强制来自自建向量检索服务（按 SOP 条款边界切片、元数据过滤、混合检索重排），每条回答附条款出处，可逐字核对原文；
3. **置信度锁**：检索置信度低于阈值时，触发固定话术「未查询到相关信息，为您升级专员处理」——「不知道」在本系统里是一等公民，是被明确设计的正常结果；
4. **权限锁**：Agent 仅挂载显式授权的工具（查订单/查保修/建工单），退款、补偿承诺等高危操作不在工具清单内，模型想越权也无路可走。

配套**情绪三级机制**：不满 → 共情并优先解决；暴怒 → 主动给出补偿选项；投诉风险 → 立即升级人工，并附结构化交接摘要（问题定位、已尝试方案、订单信息、情绪状态）。

**为什么这样做**：行业防幻觉的主流做法是「在提示词里写不要编造」——那是补丁，不是防线。我们把「绝不瞎编」拆为流程、检索、置信度、权限四层机制，每层可测试、可审计。**对售后业务，「该不办的事绝不办」比「办得快」值钱得多。**

#### 功能点二（演示钩子）：看图办事——故障照片的结构化提取（对应难点「看图」）

**做什么**：用户上传故障照片，AI 输出结构化结论（产品型号 / 故障位置 / 故障现象 / 置信度），排障流程据此**跳级**——跳过照片已能确认的环节，直接追问关键问题。

**怎么做**：多模态大模型 + 结构化提取提示词，强制输出四元组 JSON；置信度 ≥ 阈值才允许排障树跳级，**看不清就老实从头问**；图片结论与用户文字描述冲突时，以追问确认为准。

**为什么这样做**：「看图」的难点在识别后的信息利用——提取结果必须真正参与决策（决定问什么、跳到哪）。**我们用「置信度不够就不跳级」证明提取是严肃的。**

【配图位：照片 → 四元组 JSON → 排障树「跳级」标记的截图】
（图注：本图证明图片信息提取直接驱动了流程决策。）

#### 功能点三：问清与分流——口语归一、多意图拆分、政策路由（对应难点「问清」「分流」）

**做什么**：将口语化、主观描述归一化为标准故障类型；一句话混杂多个诉求时拆分为并行任务分别跟踪；按购买渠道与区域自动路由到对应的质保政策分支。

**怎么做**：基于真实售后语料提炼「口语 → 标准故障类型」映射表作为 few-shot；多意图拆分器输出任务数组并行跟踪；政策路由表（渠道 × 区域 × 品类 → SOP 分支）JSON 配置化——例如「亚马逊渠道购买：退款找平台、保修找品牌」「非国行产品不适用大陆三包」，路由路径全程可解释、可展示。

**为什么这样做**：路由规则做成 JSON 配置，换来的是**可解释性**——评委能看到「为什么走这条流程」，这正是「担起责」的工程形态。

### 方案价值与预期效果

- **对业务（可量化）**：幻觉四道防线直接压低「AI 错误承诺」的赔偿与合规风险——一次错误承诺的赔付成本远超一次转人工；多意图拆分与政策路由瞄准 70% 复杂场景，目标对标现有基线（托管率 70–80%、意图识别 90%），复杂场景托管率每提升 1 个百分点，即对应人工工时的直接节省；
- **对用户**：一次求助办成事、情绪激动时被分层对待，且永远听不到 AI 的瞎话；
- **24 小时可演示原型（落地可行性说明）**：核心链路（意图拆分 → 状态机排障 → 检索 → 工具闭环 → 防线触发）在预赛阶段已预研跑通，知识库与政策数据均来自安克官方公开资料；决赛 24 小时只做增强（语音售后通道、主动式服务），现场交付可交互的完整系统。

### 方案优势 / 创新点

- **把「致命伤」做成系统能力**：幻觉四道防线是机制设计，每层可测试、可审计；
- **状态机 + LLM 双引擎**：模型做理解与表达，流程主动权在状态机——防跑偏、防幻觉的架构级答案，体现 AI Native 思维中「对模型能力的克制使用」；
- **红线即设计**：「绝不虚构质保、绝不编造召回」被我们主动做成了产品能力；
- **每个难点有可交互证据**：三个功能点均附演示截图与可交互 Demo 链接（见自由展示区）。
