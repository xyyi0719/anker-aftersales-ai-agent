# A1 · 规则服务输出 `options` 与 `summary`

## 目标

让每轮排障追问带上**可点选项**，并把模型产出的会话摘要透传到前端。
这是 V2 引导闭环的后端一半。

## 输入依赖

- `00-契约冻结.md`（字段定义，**冻结后才能开工**）

## 产出物

| 文件 | 改动 |
|---|---|
| `mock_apis/engine.py` | 新增 `OPTION_LABELS`；排障追问时产出 `state['options']`；透传 `state['summary']` |
| `tests/test_contract.py` | 新增用例（见验收） |

### 显示文案映射表（写在 `engine.py` 顶部）

故障树里的键是系统词，用户看不懂。加一层显示映射：

```python
OPTION_LABELS = {
    '自己':     '充电宝自己充不进',
    '输出':     '给手机充电不行',
    '仍不行':   '换了也不行',
    '恢复了':   '换完就好了',
    '黑屏':     '屏幕黑屏',
    '有显示':   '屏幕有显示',
    'UVP':      '屏幕显示 UVP',
    '单边无声': '一边没声音',
    '无法连接': '连不上',
}
```

- `label` 给用户看，`value` 是故障树的选项键，点击时发送 `value`。
- 映射表覆盖两个故障树的全部选项键，**新增节点时必须同步补这里**。
- 取不到映射时回退用键本身（并且这是 bug，应当补表）。

### `summary` 透传

`state['summary'] = extracted.get('summary', '') or 上一轮的 summary`。
模型当轮没给就沿用上一轮，不允许前端拼。

## 验收指标与标准

**命令**

```bash
python -m pytest tests -q          # 全绿
python scripts/check_contract.py   # 通过
```

**必须新增的断言**

| 用例 | 断言 |
|---|---|
| 排障首问带选项 | 进 `Anker737` 的 `start` 节点时，`state['options']` 恰好 2 项，`value` 为 `自己`/`输出` |
| 选项文案说人话 | `label` 与 `value` 不相等，且 `label` 不含 `输出`/`UVP` 这类系统词 |
| 非追问不带选项 | 安全熔断、政策核保、边界拒答三种结果的 `options` 均为 `[]` |
| 选项可点着推进 | 直接把某个 `value` 当 query 发进去，故障树正确推进到对应节点 |
| 自由打字也能推进 | 用同义口语（如「给手机充不进去」）配 `branch_answer='输出'`，同样推进 |
| 选项上限 | 任何节点的 `options` 长度 ≤ 3 |
| `summary` 透传 | 传入 `summary` 后 `state['summary']` 与之相等；不传时沿用上一轮值 |
| 无图不留残影 | 先带图再发纯文字，`state['vision'] == {}` |

## 边界

- **不许改故障树的流程走向**（`TREES` 的节点与跳转关系不动）。
- **不许在前端拼 `summary`**（B 组只负责渲染）。
- 不许为了让选项好看而改故障树的选项键——键是推进逻辑的依据。
- 不新增依赖、不改接口签名。
