## 7. 出问题时的处理顺序

1. **先判断是哪一端的问题**——用契约 B 的原始 `state` 对比：后端给的字段对不对、前端渲染的对不对
2. 后端字段错 → A 组修；前端渲染错 → B 组修；两边都对不上 → **契约有问题，走变更流程**
3. 不许在没定位清楚前同时改两端（那会让问题无法归因）
